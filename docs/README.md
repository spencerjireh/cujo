# Cujo docs

Canonical spec for Cujo. The code follows these docs; a design change lands here
first. For what Cujo is and how to run it, see the [top-level README](../README.md).

- [architecture.md](architecture.md) — the model, the components, the trust
  boundary, the system map and approval sequence (Mermaid), the flow, and where
  each piece runs.
- [spec.md](spec.md) — the contracts the code follows: the trigger, the sandbox
  run and its check reports, findings and the hard rules, and the approval
  model.
- [decisions.md](decisions.md) — every load-bearing choice and its reason.
- [demo.md](demo.md) — the three demo pull requests and the judging narrative
  (tentative).
- [hackathon.md](hackathon.md) — the event Cujo is built for: dates, requirements,
  judging, tracks.
- [trueforge.md](trueforge.md) — TrueForge reference: concepts, the agent spec,
  and driving it via the SDK.
- [sources.md](sources.md) — where the fetched facts came from, and when.
