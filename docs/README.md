# Cujo docs

The design of record. The code follows these docs; a design change lands here
first. For what Cujo is and how to run it, see the [top-level README](../README.md).

- [architecture.md](architecture.md) — the components, the trust boundary, every
  crossing, the block and the unlock, and the deployment.
- [spec.md](spec.md) — the contracts the code follows, numbered 1 to 12. Current
  rules only; each cites the decisions behind it.
- [decisions.md](decisions.md) — every load-bearing choice, indexed, in a short
  template: status, decision, why, rejected options, references.
- [decisions-archive.md](decisions-archive.md) — the full text of the entries a
  later decision fully reversed.
- [../brand/brand.md](../brand/brand.md) — the brand: logo, palette, type, voice,
  and how the UI, README, and video use them.
